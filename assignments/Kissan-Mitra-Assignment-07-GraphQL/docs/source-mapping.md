# Source mapping

This assignment package follows the uploaded CS543 Assignment 7 and GraphQL hands-on tutorial:

- One GraphQL service, one schema, query operations, and a mutation.
- A relational database table with seeded sample rows.
- Apollo Server with resolvers that execute parameterized SQL.
- A simple HTML/CSS client using `fetch()` to send GraphQL POST requests.
- A before/after mutation demonstration plan.

The sample entity and all UI labels have been adapted to the Kissan-Mitra Catalogue / Farm Product Listing service rather than CampusEats or Campus Library.
